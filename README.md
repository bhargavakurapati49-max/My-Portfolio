# Kurapati Bhargava — Developer Portfolio

A responsive React + Vite portfolio showcasing full stack experience, projects, skills, and education.

## Run locally

Install Node.js 20+ and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project**, then import the repository.
3. Select **Vite** if asked. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. New pushes to your connected branch can trigger redeploys.

## Deploy on Netlify

Import your GitHub repository, use build command `npm run build` and publish directory `dist`.

## Before publishing

- Confirm your contact email and LinkedIn URL.
- Add your GitHub profile link if desired (not provided in the résumé).
- Add screenshots and links only for projects you are permitted to publish.
- Review the included PDF résumé for any information you prefer not to make public.

All project summaries are based on the supplied résumé. No private employer source code is included.
